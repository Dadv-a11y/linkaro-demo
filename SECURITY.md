# Politique de sécurité

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité dans Linkaro, **ne la publiez pas** (ni issue publique, ni réseaux sociaux). Écrivez à l'équipe : `security@` _(adresse à définir avec le nom de domaine définitif)_.

Merci d'indiquer :

- la description de la faille et son impact possible ;
- les étapes pour la reproduire ;
- vos coordonnées, si vous souhaitez être recontacté(e).

Nous accusons réception sous 72 heures et vous tenons informé(e) de la correction. Ne testez que sur vos propres comptes, et n'accédez pas aux données d'autres utilisateurs.

## Pour l'équipe

Les principes, mesures et procédures (incident, conservation des données, conformité à la loi n° 2024/017) sont décrits dans [`docs/architecture/02-securite-et-conformite.md`](docs/architecture/02-securite-et-conformite.md).
